# 🎓 LJ University – Smart Campus

A modern **University Management System** built using **HTML, CSS, JavaScript, Bootstrap 5, Font Awesome, and LocalStorage**.

## 🚀 Features

* 🔐 Login & Registration
* 👨‍💼 Admin Dashboard
* 👩‍🏫 Faculty Dashboard
* 🎓 Student Dashboard
* 👥 Student & Faculty Management
* 📚 Course Management
* 💳 Fee Payment
* 📄 Document Generation
* 📢 Announcements
* 💾 LocalStorage Data Storage
* 📱 Responsive UI

## 🛠️ Technologies

* HTML5
* CSS3
* JavaScript
* Bootstrap 5
* Font Awesome
* Animate.css
* LocalStorage

## ▶️ Run Project

1. Clone the repository.
2. Open `index.html` in your browser.
3. Or use **VS Code Live Server**.
